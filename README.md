# Иероглифы — карточки для изучения китайского

Веб-приложение: работает в браузере на iPhone, Android и компьютере, устанавливается на экран «Домой» и работает без интернета.
Сервер не нужен: это статический сайт для GitHub Pages. Уровни и прогресс хранятся в браузере каждого ученика.

## Как пользоваться
- Карточка с иероглифом. Нажатие на карточку показывает пиньинь, перевод и кнопку озвучки.
- «Знаю» убирает карточку из колоды. «Не знаю» показывает ответ, и карточка уходит в конец колоды.
- Уровень пройден, когда на всех карточках нажато «Знаю». Незаконченное прохождение сохраняется.

## Свои уровни
Книга Excel (.xlsx), CSV или JSON: столбец A — иероглиф, B — пиньинь, C — перевод.
Каждый лист Excel — отдельный уровень. Примеры лежат в `examples/`.

```
#название: Урок 5. Еда
#описание: Продукты и напитки
иероглиф;пиньинь;перевод
米饭;mǐfàn;рис
茶;chá;чай
```

Учитель раздаёт уровни:
- **ссылкой** (⋮ у уровня → «Отправить ссылкой»): уровень целиком зашифрован в самой ссылке;
- **файлом**: ученик выбирает его через «Загрузить уровень».

## Базовые уровни на сайте
Уровни из папки `levels/` видят все ученики. Чтобы добавить уровень:
1. Положите файл (.xlsx, .csv или .json) в папку `levels/`.
2. Допишите имя файла в `levels/index.json`, например `["basic.json", "урок5.xlsx"]`.

Через пару минут GitHub Pages обновит сайт, и уровень появится у всех при следующем открытии.

## Разработка
Сборка не нужна: обычные HTML, CSS и JavaScript-модули.

```bash
python -m http.server 8765
```

Тесты импорта: откройте http://localhost:8765/tests/.

При изменении файлов приложения увеличьте версию `CACHE` в `sw.js`, чтобы у пользователей быстрее обновился кэш.
